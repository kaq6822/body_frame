# BodyMark 구현 검증

2026-11-05, 검수된 디자인 방향을 회원·레슨 중심의 오프라인 Flutter 앱에 반영했다.

## 반영한 동작

- 회원 목록·검색·등록·수정·상세·삭제 및 회원 / 기록 / 설정 탐색.
- 운동 시작 배경·목표·통증/주의사항·회원 전달·강사 관찰·메모의 선택 기록.
- 실제 레슨 날짜·시각, 작성·수정 시각, 사진 촬영 시각을 분리한 기록.
- 사진 없는 일지, 사진만 있는 기록, 일지와 사진을 함께 저장하는 흐름.
- 수업 전·후·정기 사진, 4방향 순차 촬영·재촬영·건너뛰기·일부 사진 연결.
- 같은 회원·같은 방향의 이전 사진 가이드. 현재 작성 중인 사진도 기준으로 사용.
- 회원별 비교 선택, 같은 레슨 전·후 비교, 비교·공유 미리보기, 이름/메모 기본 비공개.
- 기존 사진과 메모를 보존하는 DB 이전 및 기존 미연결 기록의 명시적 회원 연결.
- 데이터·개인정보·촬영 안내, 오류/재시도, 작성 취소·삭제 범위 확인.
- BodyMark 표시 이름, bodymark Dart 패키지, com.bodymark.bodymark Android/iOS 식별자.
- 기존 벡터 심벌에서 렌더링한 Android/iOS 개발용 앱 아이콘.

자동 테스트는 데이터 이전, 원본 저장, 트랜잭션 실패 롤백, 회원별 삭제 범위,
다른 회원의 촬영 기준·비교 차단, 저장 전 사진 기준, 레슨 안의 전후 비교와
회원 등록→사진 없는 일지 저장→열람을 포함한다. 기존 카메라·사진·비교·공유 테스트도 통과했다.

Android 네이티브 저장 확인에서 회원 1명에 일지만 있는 레슨 1개와 메모 없이 사진만 있는
레슨 1개를 기록했다. 사진은 960×1280 원본 파일, 상대경로, 수업 전 구분과 별도 촬영 시각으로
저장됐고 실제 레슨 시각과 작성 시각도 달랐다. 테스트 데이터는 합성 이름과 에뮬레이터 가상
카메라 장면만 사용했다.

## 해석과 변경 영향

이 결과는 46개 정적 시안의 모든 픽셀 및 모든 물리 기기 조건이 동일하다는 의미는 아니다.
시뮬레이터 결과와 실물 기기의 카메라·보관함·공유 검증을 구분한다. 실기기·배포 검증의
잔여 항목은 ROADMAP.md에서만 관리한다.

새 패키지 식별자는 기존 com.bodyframe.* 설치본과 별도 앱으로 취급된다. OS는 이전 앱의
샌드박스를 새 식별자에 자동 이전하지 않는다. 같은 컨테이너 안의 v1 DB를 보존하는 이전은
테스트했으며 기존 DB 파일명은 유지했다. 더 높은 버전의 DB는 자동 삭제하지 않는다.

현재 Flutter SDK의 iOS 빌드 과정에서 최소 지원 버전이 15.0으로 갱신됐다.
릴리스 서명·스토어 배포는 수행하지 않았다. 기존 analysis_options.yaml 변경은 유지했고,
pubspec.lock의 기존 변경을 보존하면서 Flutter 한국어 현지화 SDK 의존성을 추가했다.
