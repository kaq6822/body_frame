# BodyMark 브랜드와 화면 디자인

BodyMark는 필라테스·요가·피트니스 강사가 회원의 레슨과 체형 변화를 기록하는
도구다. 브랜드 문구는 **같은 구도로, 변화를 기록하다**다. 체형을 평가하거나
목표 체형을 강요하지 않고, 같은 구도의 사진과 레슨 일지를 차분하게 쌓는다.
시각 기준은 Stitch 디자인 문서(BodyMark Precise Posture System)이고, 앱과 맞지
않는 부분은 아래 결정이 우선한다.

## 색

- 주요 조작은 딥 슬레이트 시안 `#0E7490`(눌림 `#155E75`)을 쓴다.
- 측정·가이드 시안 `#06B6D4`는 수평 잠금, 촬영 기준선, 카메라 안 활성 방향에만
  쓴다. 밝은 면에서 글자 색으로 쓰지 않는다.
- 경고 앰버 `#F59E0B`는 면·선에만 쓰고, 밝은 면의 경고 글자는 `#B45309`를 쓴다.
- 바탕 `#F8FAFC`, 카드 `#FFFFFF` + 1px `#E2E8F0`, 강조 테두리 `#CBD5E1`.
  글자는 `#0F172A` / `#475569` / `#64748B` 세 단계다. 보조 장식색(indigo)은 쓰지
  않는다.
- 다크 모드는 같은 관계를 slate 900 바탕(`#0F172A`)과 slate 800 면(`#1E293B`)
  위에서 유지하고, 주요 색은 `#7DD3E8`로 밝힌다.
- 카메라는 뷰파인더 `#090D14`, HUD 면 `rgba(15,23,42,.78)` + 1px
  `rgba(255,255,255,.16)`을 쓴다. 사진 letterbox와 사진 위 컨트롤은 테마와 무관한
  고정 중립색이라 피부톤·명암 판단에 색이 개입하지 않는다.

## 글꼴

Pretendard(SIL OFL 1.1)를 앱에 번들한다. 한글을 지원하는 Inter 계열이라 Stitch의
Inter와 인상이 같다. 400/500/600/700 네 굵기만 쓰며, 라이선스 원문은 앱 시작 시
오픈소스 라이선스에 등록한다. 날짜·시각·건수·용량·각도는 tabular figures로 폭을
고정한다. 스케일은 제목 24/700, 소제목 18/600, 본문 16·14·13, 라벨 14·12·11/600.

## 모양과 배치

- 카드·입력 r8, 버튼 r6, 다이얼로그·바텀시트 r12. 완전 둥근 모양은 작은 상태
  pill에만 쓴다. 그림자 대신 1px 테두리로 면을 나눈다.
- 주요 버튼은 높이 48dp 이상, 모든 터치 대상은 48×48dp 이상이다.
- 화면 가로 여백은 16dp다. 주요 동작은 하단 고정 영역(`BottomActionBar`)에 둔다.
- 4방향(정면·좌측면·우측면·후면)은 `DirectionStepper` 하나로 표시한다. 비활성,
  기록됨(체크 + 주요 색 테두리), 활성(주요 색, 카메라에서는 측정 시안) 세 상태다.
- 확인 다이얼로그는 아이콘 배지, 질문형 제목, 함께 사라지는 범위, 취소·확인 순서를
  따른다. 삭제는 오류 색 확인 버튼을 쓰고, 작성 중 나가기는 "계속 작성"을 주요
  버튼으로 둔다.

## Stitch에서 가져오지 않는 것

생성 모델 사진, 측정 수치(`-3.2° Tilt` 등), 잠금·Private 배지, 큰 그림자, 사진
cover 크롭. 체형 사진은 언제나 원본 비율로 contain 표시한다.

## 회귀 검증

`test/design/responsive_ui_test.dart`와 `test/core/widgets/`가 320dp 화면, 2배
글꼴, 밝은/어두운 테마, 여러 사진 비율에서 잘림·넘침이 없는지 확인한다. 배포 준비와
남은 작업은 `ROADMAP.md`에서 관리한다.
