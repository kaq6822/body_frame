# Body Frame 브랜드와 화면 디자인

브랜드 문구는 **같은 프레임, 쌓이는 변화**다. 성과를 평가하거나 특정 체형을
목표로 강요하지 않고, 자신의 모습을 같은 구도로 남기며 변화를 살펴보는 도구로
표현한다. 이름과 프레임 안 인물 심벌은 기존 Body Frame을 이어 간다.

포레스트 그린 `#28614F`를 주요 조작에, 따뜻한 뉴트럴 `#F8F7F2`를 밝은 화면
바탕에 사용한다. 다크 모드도 같은 색의 관계를 유지한다. 사진 주변은 테마와
무관한 중립색으로 두어 피부톤과 명암 판단에 색상이 개입하지 않게 한다.

제목과 본문, 보조 정보를 굵기와 간격으로 구분한다. 카드에는 옅은 테두리를 쓰고,
주요 버튼은 높이 52px를 확보한다. 사진 프레임은 기존 12px 모서리를 유지한다.

촬영부터 시작하는 기존 동선을 유지한다. 기록이 없으면 촬영과 갤러리 등록을
안내하고, 기록이 있으면 건수와 사진 수, 새 기록 버튼을 제공한다. 기록 스트립은
가로·세로·정사각 사진 모두 원본 비율을 보존한다. 날짜와 라벨은 좁은 화면에서
줄바꿈한다.

비교는 날짜 선택, 방향 선택, 사진 비교의 세 단계다. 날짜 선택에서는 기록 사이의
기간과 현재 선택 상태를 보여준다. 다른 쪽에 선택된 기록은 선택할 수 없는 이유를
표시한다. 날짜와 방향 선택 화면은 스크롤할 수 있어 큰 글꼴에서도 다음 버튼에
접근할 수 있다. 촬영 방향 버튼도 축소하지 않고 줄바꿈하며 48px 터치 영역을
유지한다.

아래 이미지는 390×844 논리 픽셀 크기의 실제 Flutter 위젯 렌더링이다. 미리보기에는
호스트의 한글 폰트를 사용했으며, 제품은 플랫폼 기본 폰트를 사용한다. 기기 상태바,
실제 카메라 영상, 플랫폼 권한창은 포함하지 않는다.
