# 실기기 스모크 테스트

스토어 제출 후보 빌드에서 아래 핵심 흐름만 실기기로 확인합니다. 결과에는 기기, OS,
빌드 번호, 성공 여부와 실패 화면 또는 로그를 함께 남깁니다.

## 테스트 조합

- [ ] Android 10(API 29) 기기
- [ ] Android 13 이상 기기
- [ ] iPhone

## 설치와 권한

- [ ] 새로 설치한 앱 이름이 `Body Frame`으로 표시된다.
- [ ] 촬영 화면에 처음 들어갈 때 카메라 권한만 요청하고 마이크 권한은 요청하지 않는다.
- [ ] 카메라 권한을 거부해도 안내 후 다시 시도하거나 이전 화면으로 나갈 수 있다.
- [ ] Android 13 이상에서 갤러리 등록 시 광범위한 저장소 권한 없이 시스템 선택기가 열린다.
- [ ] iOS에서 사진 선택·저장 권한 문구가 앱 기능과 일치하고, 거부 후에도 앱이 종료되지 않는다.

## 연속 세션 촬영

- [ ] 홈의 촬영 버튼을 누르면 바로 카메라가 열리고 `1 / 4 · 정면`부터 시작한다.
- [ ] 셔터를 누르면 화면을 벗어나지 않고 다음 방향으로 자동 전환된다.
- [ ] 건너뛰기로 방향을 넘길 수 있고, 진행 칩을 눌러 이전 단계로 돌아가 재촬영할 수 있다.
- [ ] 마지막 컷을 찍으면 리뷰 화면에서 찍은 컷이 한눈에 보이고, 한 번의 저장으로
  하나의 기록에 모두 들어간다.
- [ ] 같은 날 다시 촬영하면 새 기록을 만들지 않고 기존 기록에 사진이 추가된다.
- [ ] 방향별 최신 이전 사진만 반투명 가이드로 표시되고, 켜고 끄거나 투명도를
  조절해도 비율이 왜곡되지 않는다.
- [ ] 촬영 결과 원본에는 이전 사진 가이드와 격자선이 합성되지 않는다.
- [ ] 앱을 백그라운드로 보냈다가 복귀하거나 다른 카메라 앱을 사용한 뒤에도 촬영을 재개할 수 있다.
- [ ] 갤러리 등록, 사진 교체, 삭제 후 앱을 재실행해도 결과가 유지된다.
- [ ] Android 개발자 옵션의 `활동 유지 안 함`을 켠 상태에서 갤러리 선택 후
  돌아오면 등록 목록에만 결과가 복구되며 자동 저장되지 않는다.
- [ ] 같은 조건에서 사진 교체 결과는 `교체 적용`을 누르기 전까지 기존 원본을
  변경하지 않는다.

## 기기 이전

- [ ] Android 기기 간 전송(D2D)으로 새 기기에 DB와 사진이 함께 옮겨지고, 옮긴
  기기에서 사진을 실제로 열 수 있다.
- [ ] Android 클라우드 자동 백업에는 앱 데이터가 포함되지 않는다.
- [ ] iOS Quick Start 전송 후 새 기기에서 기록과 사진을 열 수 있다.
- [ ] iOS iCloud 백업 복원 후에도 기록과 사진을 열 수 있다.

## 내보내기

- [ ] Android 10과 Android 13 이상에서 비교 이미지를 갤러리에 저장할 수 있다.
- [ ] 비교 이미지 공유 시 선택한 레이아웃과 안내 문구가 일치한다.
- [ ] 포함 옵션(촬영일·대상 라벨·메모·격자)을 켜고 끈 결과가 생성 이미지에 그대로 반영된다.

## 오프라인

- [ ] 비행기 모드에서도 촬영, 기록 조회, 비교의 핵심 기능이 동작한다.
- [ ] 오류 로그에 대상 라벨, 메모, 로컬 파일 경로가 노출되지 않는다.
