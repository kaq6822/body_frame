# 실기기 스모크 테스트

스토어 제출 후보 빌드에서 아래 핵심 흐름만 실기기로 확인합니다. 결과에는 기기, OS,
빌드 번호, 성공 여부와 실패 화면 또는 로그를 함께 남깁니다.

## 테스트 조합

- [ ] Android 10(API 29) 기기
- [ ] Android 13 이상 기기
- [ ] iPhone

## 설치와 권한

- [ ] 새로 설치한 앱 이름이 `BodyMark`로 표시된다.
- [ ] 화면 글꼴이 Pretendard로 표시되고, 한글·날짜·숫자가 네모(□)나 대체 글꼴로
  깨지지 않는다.
- [ ] 촬영 화면에 처음 들어갈 때 카메라 권한만 요청하고 마이크 권한은 요청하지 않는다.
- [ ] 카메라 권한을 거부해도 안내 후 다시 시도하거나 이전 화면으로 나갈 수 있다.
- [ ] Android 13 이상에서 갤러리 등록 시 광범위한 저장소 권한 없이 시스템 선택기가 열린다.
- [ ] iOS에서 사진 선택·저장 권한 문구가 앱 기능과 일치하고, 거부 후에도 앱이 종료되지 않는다.

## 회원과 레슨

- [ ] 회원을 등록하고 목록·상세에서 이름, 목표, 주의사항을 확인할 수 있다.
- [ ] 레슨 일지를 사진 없이 메모만, 또는 메모 없이 사진만 저장할 수 있다.
- [ ] 레슨 일시, 사진 촬영 일시, 작성 일시가 상세에서 구분되어 보인다.
- [ ] 회원 미연결 기록이 임의의 회원에게 자동으로 배정되지 않는다.
- [ ] 작성 중 뒤로 가면 버릴지 확인하고, 회원·레슨·사진 삭제는 범위를 알리는
  확인창을 거친 뒤에만 지워진다.

## 촬영

- [ ] 촬영 화면에 들어가면 `1 / 4 · 정면`부터 시작하고, 셔터를 누르면 다음 방향으로
  자동 전환된다. 건너뛰기와 이전 단계 재촬영이 동작한다.
- [ ] 수평계가 기울기에 따라 움직이고, 수평일 때 상태가 바뀐다. 설정에서 끄면
  사라진다. 센서가 없거나 거부돼도 촬영은 막히지 않는다.
- [ ] 격자는 기본으로 보이고, 켜고 끄거나 조절해도 비율이 왜곡되지 않는다.
- [ ] 이전 사진 가이드는 선택한 회원·같은 방향의 최신 사진만 반투명으로 보이고
  투명도를 조절할 수 있다.
- [ ] 촬영 결과 원본에는 가이드와 격자선이 합성되지 않는다.
- [ ] 마지막 컷 뒤 리뷰 화면에서 한 번의 저장으로 하나의 레슨 기록에 모두 들어간다.
  저장 중에는 입력과 재촬영이 막히고 여러 번 눌러도 한 번만 반영된다.
- [ ] 저장이 실패하면 입력과 임시 원본이 남고 재시도로 이어진다.
- [ ] 백그라운드 복귀나 다른 카메라 앱 사용 뒤에도 촬영을 재개할 수 있다.

## 갤러리 등록

- [ ] 저장 중에는 항목 제거·방향·촬영일·메모 변경과 사진 선택이 막히고, 시스템·앱바
  뒤로가기도 막힌다.
- [ ] 사진 선택·EXIF 읽기가 끝나기 전에는 일괄 저장이 차단된다.
- [ ] Android 개발자 옵션의 `활동 유지 안 함`을 켠 채 갤러리에서 돌아오면 선택
  결과가 목록에만 복구되고 자동 저장되지 않는다.
- [ ] 저장 실패 시 목록과 원본이 그대로 남고 재시도할 수 있다.

## 기록과 비교

- [ ] 회원 비교에서 이전·이후 레슨을 고르고 방향을 선택해 나란히 보기와 겹쳐 보기로
  확인할 수 있다.
- [ ] 비교 기간 문구가 서머타임이 낀 달에도 달력 일수와 일치한다.
- [ ] 사진 교체는 `교체 적용`을 누르기 전까지 기존 원본을 바꾸지 않고, 갤러리 등록·
  교체·삭제 결과가 앱 재실행 뒤에도 유지된다.

## 설정 저장

- [ ] 격자·앱 설정을 연속 변경할 때 마지막 요청까지 저장 진행 표시가 유지되고,
  모든 요청이 끝난 뒤 마지막 결과의 성공·실패 표시가 나온다.
- [ ] 설정 저장이 실패해도 마지막 선택값은 화면에 남고 재시도로 저장할 수 있다.

## 기기 이전

- [ ] Android 기기 간 전송(D2D)으로 새 기기에 DB와 사진이 함께 옮겨지고, 옮긴
  기기에서 사진을 실제로 열 수 있다.
- [ ] Android 클라우드 자동 백업에는 앱 데이터가 포함되지 않는다.
- [ ] iOS Quick Start 전송 후 새 기기에서 기록과 사진을 열 수 있다.
- [ ] iOS iCloud 백업 복원 후에도 기록과 사진을 열 수 있다.

## 내보내기

- [ ] 공유 이미지는 2단계(구성 후 미리보기)로 진행되고, 미리보기에서 구성 수정으로
  돌아갈 수 있다.
- [ ] Android 10과 Android 13 이상에서 이미지를 갤러리에 저장할 수 있고, iOS에서는
  사진 보관함에 저장된다.
- [ ] 선택한 레이아웃과 포함 옵션(촬영일·회원 이름·메모·격자)이 생성 이미지에
  그대로 반영된다. 이름과 메모는 기본으로 포함되지 않는다.
- [ ] 미리보기와 생성 이미지의 구도가 일치하고 원본 비율이 유지된다.

## 설정과 안내

- [ ] 설정에서 데이터 보관 안내, 개인정보 안내, 저장 공간 관리, 오픈소스 라이선스로
  이동하고 돌아올 수 있다.
- [ ] 두 안내 화면이 서로 이동할 수 있고, 앱 안에 백업·복원 기능이 있다는 표현이 없다.

## 오프라인

- [ ] 비행기 모드에서도 촬영, 레슨 기록 조회, 비교의 핵심 기능이 동작한다.
- [ ] 오류 로그에 대상 라벨, 메모, 로컬 파일 경로가 노출되지 않는다.
