# Body Frame

내 체형 사진을 기기 안에 기록하고 날짜별로 비교하는 Android/iOS Flutter
앱입니다. 로그인이나 서버 없이 동작합니다.

앱을 열면 바로 기록 타임라인이 보이고, 촬영 버튼 한 번으로 정면 → 좌측면 →
우측면 → 후면을 이어서 찍어 하나의 기록으로 저장합니다. 촬영 화면에서는 격자와
직전 촬영 사진을 반투명 가이드로 겹쳐 같은 구도를 재현할 수 있습니다.

- 연속 세션 촬영(방향별 건너뛰기·개별 재촬영), 갤러리 사진 등록
- 날짜별 기록 관리와 원본 사진 보기
- 전후 비교: 좌우 비교 / 겹쳐 보기 / 슬라이더 비교, 비교 이미지 생성·공유
- 본인 외의 사람을 찍은 기록은 대상 라벨로 구분

데이터 이전은 OS의 기기 간 전송에 위임합니다. 앱 안에 별도 백업 기능은 없습니다.

## 실행

```sh
flutter pub get
flutter run
```
